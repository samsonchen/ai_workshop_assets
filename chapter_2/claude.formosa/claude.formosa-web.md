# claude.formosa 活動網站規格

- 可以同時時在電腦與手機上使用
- 需要中英文雙語
- Discord 的連結在電腦版上還需要顯示對應的 QRCode 供手機掃描, 但手機版網站則不需要 QRCode.
- 最喜灣的網站風格 [SpaceX](https://www.spacex.com/)
- 如果需要, 資料內也有 Video 可以應用
- 不是每一張照片跟每一個影片都一定要編入網站內容，可以選擇部份內容達成圖文平衡，並且內容不會貧乏但也不會過多
- 過去的每一場 event 都應該有自己的一頁來讓大家回顧過去的活動
- 提供資料的文字不要照單全收的照用，應該要經過修飾並且要有一致性
- 文字語氣參考 samson-voice SKILL
