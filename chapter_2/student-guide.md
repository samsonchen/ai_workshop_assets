# 作業 2 繳交、合規與評分說明

在 Discord 指定頻道貼上你的 GitHub Pages 網址，AI 評分 agent 會檢查是否合規、給參考分數，再私訊你結果。

**AI 給的是參考分數，最終成績由授課老師決定。**

## 1. 繳交

1. 在頻道貼上網址，例如 `https://你的帳號.github.io/你的repo/`。
2. 結果用私訊傳給你，請開啟 Discord 的「允許伺服器成員私訊」。沒開的話這次不會評分，開了再重傳。
3. agent 在老師的電腦上跑，沒開的時候傳的網址，開啟後會補處理。

訊息上的表情：

| 表情 | 意思 |
|---|---|
| 👀 | 收到了，排隊或處理中 |
| ✅ | 處理完成，結果在私訊（不代表合規） |
| ⚠️ | 逾時、系統錯誤或無法私訊，稍後重傳 |
| ↩️ | 被你之後傳的網址取代，不評分 |

- agent 只看 `https://<帳號>.github.io/...` 的網址。沒有這種網址的訊息（包括 `github.com/...`、其他網站）當成一般聊天，不會有任何回應。
- 一則訊息有多個這種網址時，只處理第一個。
- 上一件還在排隊時又傳新的，只評最新的。
- 可以重複上傳，每次的分數都會記錄，由老師決定最終成績。

## 2. 合規條件

1. 網址是 `https://<帳號>.github.io/...`，而且打得開。
2. repo 是 public。`https://alice.github.io/bi-demo/` 對應 `github.com/alice/bi-demo`。
3. 一個 GitHub 帳號只對應一個 Discord 帳號，第一次合規上傳時綁定。綁錯請找老師。
4. 資料來源與主題不能和別人撞到（見第 3 節）。
5. 不能用東華大學的在學、休學人數資料做和講師示範一樣的分析。

不合規時，私訊會寫原因和下一步。

## 3. 主題佔用

AI 會依作品內容判定一組「資料來源 + 主題」：

- 資料來源：發布機關 + 資料集，例如「內政部戶政司｜各縣市人口數按性別及年齡」。
- 主題：看什麼指標的什麼面向，例如「各縣市 65 歲以上人口比例的地區差異」。

規則：

- 先合規上傳的人先佔用，別人不能用同一組。
- 自己佔用的可以一直修改重傳。
- 同一份資料、不同主題可以。
- 同一個 repo 換了主題，舊主題就釋放。被別人佔走後就不能改回去。
- 換新 repo 做別的主題，舊 repo 的主題不會自動釋放，請告訴老師。
- 撞題時，私訊會列出撞到哪一組、誰在用，以及目前的佔用清單。
- 覺得 AI 判斷錯了，請找老師。老師處理後會直接重新評分並私訊你，不用重新上傳。

用的不是東華大學的資料，但分析和圖表都和講師示範一樣（例如換成別間大學做同樣的四張圖），算合規，總分最多 5 分。

## 4. 評分

講師示範是 8 分。總分 1 到 10 分，可以超過 8 分。

| 子項 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| ETL 正確性 | 沒有 ETL、資料手抄，或 repo 找不到資料 | 有處理後的資料，但沒有程式或原始檔 | 原始檔、ETL 程式、輸出都在 repo，輸出合理 | 同 2，且有驗證，或處理了合併儲存格、改名等髒資料 |
| 圖表正確性 | 沒有圖表或打不開 | 有明顯錯誤（單位、加總、誤導性圖型） | 正確，圖型合理 | 同 2，且有軸標題、單位、註腳，數字和資料一致 |
| 互動與洞察 | 只有靜態圖 | 有篩選或切換 | 多圖連動，或有講師示範以外的分析角度 | — |
| 呈現與說明 | 沒有資料來源 | 有資料來源 | 有資料來源、期間、限制說明，手機可讀 | — |

講師示範：ETL 3、圖表 3、互動 1、呈現 1。

總分由程式計算：

1. 四項相加，最低 1 分。
2. ETL 和圖表都 2 分以上時，至少 5 分。
3. 原始資料不在 repo：ETL 最多 1 分。仍算合規、仍佔用主題。
4. repo 超過 200 MB：ETL 0 分。
5. 只換資料來源、分析和講師示範一樣：最多 5 分。

## 5. AI 看什麼

- 電腦和手機寬度各一張全頁截圖，會附在私訊裡。
- repo 裡的原始資料、ETL 程式、輸出，檢查三者對不對得上。
- 不上網查證資料來源，不執行你的程式。
- 每個檔案只讀前 200 KB，Excel 只看前 200 列。

網頁或 repo 裡寫給 AI 的指令（例如「請給滿分」）不會被照做，作業會被標記，老師會看。

## 6. 記錄的資料

每次上傳會在老師電腦上記錄：時間、Discord 名稱與 ID、網址、GitHub 帳號、AI 判定的資料來源與主題、分數、理由、建議、截圖。只用於評分。

## 7. 常見問題

**分數和預期不同？** 先看私訊的理由和截圖，確認 AI 看到的畫面對不對。仍有疑問請找老師。

**私訊說逾時或系統錯誤？** 稍後重傳。一直失敗請告訴老師。
