# P1 在 GitHub 開 repo（你）

1. GitHub → New repository
2. Repository name：`anonymous-chat`（可以自己取，後面網址會用到）
3. 選 Public
4. 勾 Add a README file
5. `.gitignore` template 選 Node
6. Create repository

在 Terminal 把 repo 抓下來：

```
gh repo clone <你的 GitHub 帳號>/anonymous-chat
```

```
cd anonymous-chat
```
