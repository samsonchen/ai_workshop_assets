# P0 開始前

這份 Project 流程從「你目前知道的東西」開始，讓 Claude Code 幫你補上你還不知道的部分。agent 的程式、Discord 的設定文件，都是流程中產出的，不是事先給你的。

## 你已經知道的

- GitHub：開 repo、commit、push
- `/grilling` 這個 skill 的用途
- 這個 agent 用 Python 跑、用 `claude -p` 看照片、用 Discord 的 Gateway（bot）模式收訊息（你在別的對話討論過，或有人建議過）
- 紀錄要存成一個可以一直往下加的 Excel 檔

## 你還不知道的（交給 Claude Code）

- 用哪一個 Discord 的 Python 套件、怎麼接
- `claude -p` 怎麼呼叫、怎麼讓它回固定格式、怎麼把照片交給它
- 好幾個人同時傳時怎麼排隊
- 檔名、Excel 儲存格怎麼清洗才不會出問題
- 那幾段「防護」具體怎麼寫

不知道的部分不用自己查。請 Claude Code 解釋到你看得懂，並寫進文件裡。

## 要先裝好的（課前安裝清單已完成）

- Claude Code，並且 `claude` 指令可以在終端機直接執行
- Git
- GitHub CLI（`gh`），並已執行過 `gh auth login`
- Python 3.12 與 uv

> 這個 Project 固定用 Python 3.12 + uv，是因為課前就請大家裝好了。實務上你可以換成別的語言或工具，agent 的做法不會差太多。

## 確認 `claude` 可以用

終端機執行：

```
claude --version
```

有版本號出來就可以。`claude -p "說哈囉"` 能得到回覆代表登入也正常。

## 兩人一組

後半段（P8）要互相傳照片測試，請先找一位同學一組。到 P5 設定 Discord 時，你們會互相加入對方的 Server。
