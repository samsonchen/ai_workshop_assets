# P6 做出 agent（Claude Code）

讓 Claude Code 依架構文件把 agent 寫出來。一次貼下面這段。

```
請依照 docs/architecture.md 把這個 agent 寫出來。先說明你打算怎麼做、會裝哪些套件，等我說「開始」再動手。

需求重點：
1. 用 Python 3.12 + uv 管理環境與相依套件
2. Discord 用 Gateway（bot）模式，要處理有圖片附件的訊息；只聽 .env 裡 CHANNEL_ID 指定的那一個頻道
3. 收到食物照片時：
   - 先對那則訊息加上 ⏳ 反應，表示收到、排隊中
   - 多張同時進來要一張一張排隊處理，不要同時開很多個 claude -p
4. 用 claude -p 分析照片，要求它回「固定格式 JSON」：是不是食物、名稱、成份、估計重量（公克）、估計熱量（大卡）。
   agent 要先解析並檢查這個 JSON：不是合法 JSON、或重量/熱量不是數字時，要回覆上傳者「分析失敗，請再傳一次」，不可以讓程式當掉。
5. 記錄：
   - 存成一個可以持續往下加的 Excel 檔（新的一列加在最後，不要覆蓋）
   - 欄位：日期時間、上傳者、食物敘述、成份、重量(公克)、熱量(大卡)、當日已攝取熱量(大卡)、照片存放位置
   - 當日已攝取熱量 = 當天（以我電腦的本地日期為準）這個頻道處理過的所有熱量加總（這一版不分人）
   - Excel 若正在被我打開而寫入失敗，要在終端機印出警告並重試，不可以讓程式當掉
6. 照片存放：
   - 存進 DATA_DIR 底下一個固定的照片資料夾
   - 檔名用「YYYY-MM-DD hh-mm-ss 食物名稱簡稱.jpg」（用 - 不用冒號，Windows 才存得了）
   - 同一秒撞名時在後面加 -2、-3
7. 不是食物時：一樣建檔、一樣存照片、一樣回覆；食物名稱欄寫「不是食物」，成份欄寫判定出來的東西（例如「馬克杯」）
8. 回覆上傳者：用「回覆該則訊息」的方式回在頻道裡（不要用私訊），內容包含是不是食物、成份、重量、熱量，最後一定要附上「當日已攝取熱量」的總數
9. 設定全部從 .env 讀：DISCORD_TOKEN、CHANNEL_ID、CLAUDE_MODEL、DATA_DIR

安全（請務必照做，之後上課會用到）：
把下面四類防護，在程式裡「各自包成一段」，用這種註解把每一段的開始和結束標清楚，讓之後可以單獨把某一段整段註解掉：

    # ==== 防護 1：claude -p 的檔案範圍隔離　開始 ====
    ...這一段的程式...
    # ==== 防護 1 結束 ====

四段分別是：
- 防護 1：呼叫 claude -p 時，把它能碰到的檔案範圍限制在「只有這一張待分析照片」的暫存資料夾，不能讓它讀到 DATA_DIR 裡別人的照片和紀錄
- 防護 2：上傳者打的字只能當「要分析的資料」，絕對不能把它接進給 claude -p 的指令裡
- 防護 3：claude -p 回來的食物名稱拿去當檔名前，先清掉 / \ .. 冒號等會讓路徑亂跑的字
- 防護 4：寫進 Excel 的文字若以 = + - @ 開頭，先處理成純文字

一開始四段防護全部開著（不要註解掉任何一段）。請在 README 或程式開頭用註解列出這四段各在第幾行附近，方便之後找。

最後：請提供用 uv 啟動 agent 的指令，並確認 .env 和 DATA_DIR 都在 .gitignore 裡。
```

說「開始」之後，等它寫完、裝好套件、給你啟動指令。**先不要 commit**，先到 P7 測。
