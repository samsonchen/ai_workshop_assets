# P7 自己測試（你）

agent 跑起來之後，對照架構文件的「驗證清單」，至少測這些：

## 基本功能

- [ ] agent 啟動後，在指定頻道傳一張**食物照片**，有先出現 ⏳，之後有回覆
- [ ] 回覆裡有：是不是食物、成份、重量、熱量、**當日已攝取熱量總數**
- [ ] 傳第二張食物照片，當日已攝取熱量**有累加上去**
- [ ] 打開 DATA_DIR：Excel 有新的一列、照片有存檔，檔名是「日期時間 + 食物名稱簡稱」
- [ ] 傳一張**不是食物**的照片（例如馬克杯），有回覆「不是食物」，而且也有建檔、也有存照片

## 多人 / 多張

- [ ] 請同組同學在你的 Server 傳一張照片，也能被處理、也有回覆（驗證「不是只有我能用」）
- [ ] 連續快速傳三張，會一張一張排隊處理完，不會亂掉或當掉

## 不會當掉

- [ ] Excel 檔正開著的時候再傳一張，agent 不會當掉（終端機有警告、會重試）
