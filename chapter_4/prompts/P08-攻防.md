# P8 攻防：關掉防護看看（你 + 同學 + 老師）

這一步由老師帶。前面你把四段防護都做好、也測到正常了；現在要**一段一段關掉**，親眼看看 agent 被影響成什麼樣子，再打開。

## 怎麼做（每一段都一樣的流程）

老師會指定這一輪關哪一段防護。對你自己的 agent：

1. 停掉 agent。
2. 在程式裡找到那一段防護的註解標記：

   ```
   # ==== 防護 N：... 開始 ====
   ...
   # ==== 防護 N 結束 ====
   ```

   把**這兩行中間**整段註解掉（每行前面加 `#`）。如果不確定怎麼註解一整段，直接請 Claude Code 幫你：「請把防護 N 那一段整段註解掉，其他不要動」。

3. 重新啟動 agent。
4. 請同組同學（或照老師的指示）傳一張圖進來。
5. 看 agent 的反應，和防護開著時比。把你看到的現象記下來。
6. 一輪結束，把那一段**改回來**（取消註解，或請 Claude Code 還原），重新啟動，確認恢復正常。

## 要觀察與討論的

- 同一支 agent、同一個模型，只差「有沒有那一段防護」，結果差多少？
- 老師會讓你用不同的 `CLAUDE_MODEL`（改 `.env` 裡那一行）各打一次。比較看看：換個模型，結果一樣嗎？這說明安全該靠模型，還是該靠程式？

> 這一步需要的測試圖片由老師提供。做完所有輪次後，**務必把四段防護全部改回開啟**，再進 P9。
