# 附錄 A：grilling 參考答案

P4-1 讓 Claude Code 問問題時，每次問的內容和順序都不一樣。這裡是一次實際問答的整理，卡住或不知道怎麼回時可以參考。**不要照抄**，用你自己的情況回答。

> Claude Code 多半會附上它的建議，你同意就回「用你的建議」。

---

**Q：有人上傳的如果不是食物（例如一張風景照、一個馬克杯），agent 要怎麼反應？**

A：還是要回覆他，告訴他「這不是食物，看起來是○○」，用你判斷出來的東西講。這種也要建檔、也要存照片，只是食物名稱那欄寫「不是食物」。

---

**Q：「當日已攝取熱量」是整個頻道加總，還是每個人分開算？「當日」用哪個時區？**

A：這一版先全部加在一起，不分人。當日就用我這台電腦的日期。分人之後可以當作業。

---

**Q：好幾個人同時傳照片，處理要花幾十秒，這段時間要不要先回應他們？**

A：收到先加一個「處理中」的小提示（例如 ⏳），然後一張一張排隊處理，處理完再回覆。

---

**Q：回覆要回在頻道裡，還是私訊給上傳者？**

A：回在頻道裡（用回覆那則訊息的方式）。因為每個人用自己的 Server，回在頻道大家看得到。

---

**Q：Excel 如果我剛好開著在看，agent 要寫入卻寫不進去，怎麼辦？**

A：不要當掉。在終端機印個警告、等一下再試。

---

**Q：食物名稱會被拿去當照片檔名。如果名稱裡有奇怪的符號（像 / 或冒號）怎麼辦？**

A：（這題其實是技術題，Claude Code 通常自己決定）請它在存檔前把這些字清掉，檔名用日期時間加名稱就好。
