# 附錄 C：老師的檢查點

每組做出來的 agent 會不一樣。下面幾項是一定要有的，沒有就請學生回到對應步驟補上。

## 架構文件（P4）

- 有清楚的資料流：上傳 → 排隊 → claude -p → 檢查 → 建檔 → 回覆
- 寫明 claude -p 要回「固定格式 JSON」，而且 agent 會檢查、不直接相信
- 安全那一節列出四類防護，每一類寫清楚在擋什麼
- 寫出至少兩個限制：熱量是估計不是量測、這一版不分人算當日熱量

## agent 程式（P6）

- 只聽 `.env` 的 `CHANNEL_ID` 一個頻道
- 收到先加 ⏳、照片一張一張排隊
- Excel 是「往下加」不是覆蓋；有「當日已攝取熱量」欄，回覆也帶這個總數
- 不是食物也會建檔、存照片、回覆
- 檔名用 `YYYY-MM-DD hh-mm-ss 名稱`（用 `-` 不是冒號），撞名會加 `-2`
- Excel 被鎖住時不會當掉
- **四段防護各自用 `# ==== 防護 N ... 開始/結束 ====` 標記，一開始全部開啟**

## 設定與安全

- `.env` 和 `DATA_DIR` 都在 `.gitignore`
- repo 裡搜不到寫死的 bot token

## 收尾（P9）

- 四段防護全部還原開啟
- 程式行為和架構文件一致

> 攻防（P8）怎麼帶、四段防護各自對應什麼攻擊、測試圖怎麼用，在另外一份老師手冊裡（不在學生 repo 內）。
