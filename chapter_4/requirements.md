# 需求說明

## 這是什麼
一個在我自己電腦上執行的 Discord agent。只要它開著，我 Discord Server 裡指定頻道的任何人傳一張食物照片進來，它就會判斷、估熱量、建檔，再回覆上傳者。agent 關掉就不處理。

## 誰會用
我自己的 Discord Server 裡、那個指定頻道的任何人，用手機或電腦都可以傳。

## 使用的流程
1. 有人在頻道裡傳一張食物照片
2. agent 收到，先回一個「處理中」的提示
3. agent 判斷：是不是食物、大概有哪些成份、估計重量與熱量
4. agent 把結果記下來、把照片存起來
5. agent 回覆上傳者這餐的結果，並附上「當日已攝取熱量」的總數

## 要記錄的內容（存成一個可以一直往下加的 Excel 檔）
- 日期時間
- 上傳者
- 食物敘述
- 成份
- 食物重量
- 食物熱量
- 當日已攝取熱量
- 照片存放位置

照片另外存進一個資料夾，檔名用「日期時間 + 食物名稱簡稱」。

## 不是食物的時候
一樣要回覆上傳者「你傳的不是食物，是某某東西」，用 agent 判斷出來的東西說明。這種照片也要建檔、也要存，只是食物名稱那欄寫「不是食物」，成份欄寫它到底是什麼。

## 畫面上 / 回覆上要有
- 收到時先有「處理中」的提示
- 處理完回覆：是不是食物、成份、重量、熱量、當日已攝取總熱量

## 不需要的
- 註冊、登入
- 長時間、大規模的雲端服務（這就是一支開著才會動的本機程式）
- （其他你確定不要的）

## 技術上我知道的
- 用 Python 3.12 + uv（課前已經裝好；實務上也可以用別的語言，這裡先固定）
- 照片用 `claude -p` 在我這台電腦上處理
- Discord 用 Gateway（bot）模式，不需要 ngrok
- 紀錄存成一個可以持續往下加的 Excel 檔
- 設定放在 `.env`：`DISCORD_TOKEN`、`CHANNEL_ID`、`CLAUDE_MODEL`、`DATA_DIR`
